A simple PWA counter/tracker app. Set a word and a target number, then tap to increment your count with visual progress feedback.

## Features
- Radial progress ring
- Tap-to-count interaction
- PWA installable (manifest.json + service worker)
- Haptic feedback on tap
- Smooth screen transitions

## How to open
Open `index.html` in any modern browser. Can be installed as a PWA.
